About DominosApp

A modern pizza ordering Web API built as a final project for the ASP.NET MVC course at SoftUni Buditel. Full-stack: REST API backend + vanilla JS frontend.

🏗 Architecture

Clean multi-project solution: Web API, Core (services), Infrastructure (EF Core), Util (logger), and Tests.

🔐 Security

ASP.NET Identity for user management, JWT tokens for API auth, role-based access (User / Administrator).

🧪 Tested

NUnit unit tests with Moq mocking for the service layer. No real database needed for tests.

📡 API

14 REST endpoints across 4 controllers: Pizza, Order, Auth, Admin. Full CRUD on all entities.

ASP.NET Core 8.0 Entity Framework Core SQL Server ASP.NET Identity JWT Bearer NUnit + Moq Vanilla JS
